# Octopus — Brand Book

**Статус:** действующие настройки сайта, перенесённые из CSS без изменения значений 20 ноября 2026 года. Это техническая библиотека текущих цветов и типографики, а не подтверждение отдельного лицензированного или специально разработанного шрифта.

## Файлы

- `colors.css` — **единый источник** основных цветовых переменных сайта и дополнительных цветовых переменных главной страницы.
- `typography.css` — **единый источник** используемых семейств шрифтов.
- `README.md` — человекочитаемая спецификация для разработки и будущего оркестратора.
- `octopus-front-button-website.jpeg` — **«Фронтальная кнопка для сайта»**: утверждённый фирменный осьминог с зелёной кнопкой GEO Pass, оригинальное изображение 1536 × 864 px без изменений.

## Типографика

- **Заголовки:** `--serif: Georgia,"Times New Roman",serif`.
- **Основной текст и интерфейс:** `--sans: system-ui,-apple-system,BlinkMacSystemFont,"Segoe UI",Arial,sans-serif`.

В настоящее время отдельные файлы шрифтов `.woff`, `.woff2`, `.ttf` или `.otf` в составе этого Brand Book не используются. Georgia и системный стек шрифтов подгружаются средствами браузера/операционной системы; поэтому внешний вид может немного различаться между устройствами. **Не выдавать используемые системные шрифты за уникально разработанный фирменный шрифт.**

## Подключение и обязательные правила

Файл `geo-pass/assets/site.css` импортирует оба файла из этой папки **до остальных правил CSS**. Это сохраняет уже существующие значения `var(--...)` на сайте. Цветовые переменные `.oh-site` теперь заданы в `colors.css` вместо дублирования в `octopus-home-2026.css`.

Для будущего оркестратора:
1. Прежде чем создавать или менять визуальные компоненты, прочитать этот файл и действующие `colors.css` / `typography.css`.
2. Не менять фирменные цвета, семейства шрифтов или маскота без утверждения владельца.
3. Если владелец утверждает новый цвет или шрифт, сначала обновить соответствующий файл Brand Book, затем проверить отображение всех затронутых страниц.
4. **Фирменная фронтальная кнопка:** использовать утверждённый оригинал `octopus-front-button-website.jpeg`. Не менять цвета, лицо, очки, пропорции или текст изображения без согласования. Другие варианты осьминога пока остаются в `geo-pass/assets/` и не переносятся автоматически.
5. `main` (документационный репозиторий) не изменяется: актуальная работа над сайтом ведётся в `preview/anna-geo-website`.

## Область текущего переноса

Перенесены **ровно те переменные, которые существовали** в `site.css` и в базовом блоке `.oh-site` файла `octopus-home-2026.css`. Остальные локальные оттенки, изображения и оформление кнопок намеренно не менялись. Сам по себе этот перенос не означает полного аудита или утверждения законченного корпоративного Brand Book.
