# Обязательные регрессионные тесты GEO Pass

Проверки выполняются **без сети, API ключей и реальных персональных данных** на Node.js 22.

Из корня репозитория:

```bash
for file in geo-pass/assets/*.js; do node --check "$file"; done
node --test geo-pass/tests/mandatory-regression.test.cjs
```

Автоматически проверяются DE/RU/EN, 14 пунктов Marketing (13 + «Другое»), выбор 1–3, запрет четвёртого, снятие выбора, свободный ввод, восстановление после возврата, отображение всех выбранных пунктов в просмотре, сохранение старых Beauty/Legal ограничений и отсутствие включённой AI-публикации для новой категории.

**Важно:** эти тесты имитируют работу браузера, но не заменяют реальную визуальную проверку страницы на телефоне, проверку фактического деплоя GitHub Pages и полноценный E2E-тест.

Нормативные требования: закрытый `AnnaTrocka306/Octopus/docs/GEO_PASS_MANDATORY_RULES.md`. GitHub Action проверяет результат **после** push; без правила защиты ветки не гарантирует блокировку неверных изменений.
