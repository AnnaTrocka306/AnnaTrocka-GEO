# Semantic Package

## Kanonische Definition

Ein **Semantic Package** ist eine logisch zusammengehörige Sammlung von Knowledge Objects, Semantic Entity, Semantic Relationship und Supporting Evidence, die gemeinsam ein bestimmtes Wissensgebiet oder einen definierten semantischen Kontext beschreiben.
