# Semantisches Paket

## Definition

Ein **Semantic Package** ist eine logisch zusammengehörige Sammlung von [Semantic Entities](Semantic_Entity.md) und ihren semantischen Beziehungen innerhalb der [Knowledge Architecture](Knowledge_Architecture.md).

Ein Semantic Package organisiert Wissen zu einem gemeinsamen Thema, einer Fragestellung oder einem Anwendungsbereich und ermöglicht dessen konsistente Wiederverwendung und Weiterentwicklung innerhalb der Knowledge Architecture.
