# Verborgener Wert einer Nutzungssituation

## Definition

Hidden User-Situation Value bezeichnet den bislang nicht ausreichend erkannten oder beschriebenen Wert einer bereits vorhandenen Leistung, Funktion oder eines Services innerhalb einer konkreten Kundensituation.

Er entsteht, wenn eine Organisation zwar weiß, **was** sie anbietet oder operativ tut, aber nicht ausreichend erkennt oder formuliert, **welches [Customer Problem](https://github.com/AnnaTrocka306/AnnaTrocka-GEO/blob/main/docs/knowledge-base/Knowledge_Dictionary/Customer_Problem.md) dadurch in einer konkreten Situation gelöst oder welches [Customer Goal](https://github.com/AnnaTrocka306/AnnaTrocka-GEO/blob/main/docs/knowledge-base/Knowledge_Dictionary/Customer_Goal.md) unterstützt wird**.

Ein Hidden User-Situation Value kann im Rahmen der [Reality Validation](https://github.com/AnnaTrocka306/AnnaTrocka-GEO/blob/main/docs/knowledge-base/Knowledge_Dictionary/Reality_Validation.md) sichtbar werden, wenn eine reale Nutzung zeigt, dass eine bekannte Leistung in einer bestimmten Situation einen größeren oder anderen Kundennutzen erzeugt als aus ihrer bloßen operativen Beschreibung hervorgeht.

Nach seiner Bestätigung wird dieser Zusammenhang Bestandteil der [Validated Current Reality](https://github.com/AnnaTrocka306/AnnaTrocka-GEO/blob/main/docs/knowledge-base/Knowledge_Dictionary/Validated_Current_Reality.md) und kann bei der Identifikation oder Präzisierung einer [Recommendation Situation](https://github.com/AnnaTrocka306/AnnaTrocka-GEO/blob/main/docs/knowledge-base/Knowledge_Dictionary/Recommendation_Situation.md) berücksichtigt werden.

Der Begriff beschreibt damit nicht eine neue Leistung, sondern einen bereits real vorhandenen Service oder ein vorhandenes Merkmal, dessen Empfehlungsrelevanz erst sichtbar wird, wenn sein Wert innerhalb einer konkreten Nutzungssituation verstanden wird.
