# Wissensarbeit

## Definition

Ein **Knowledge Paper** ist eine eigenständige Wissensarbeit innerhalb einer [Knowledge Architecture](Knowledge_Architecture.md), die genau eine zentrale Fragestellung beantwortet und dokumentiertes Wissen in einer reproduzierbaren Form bereitstellt.

Knowledge Papers bilden die grundlegenden Bausteine einer [Knowledge Base](Knowledge_Base.md). Sie dokumentieren nachvollziehbare Erkenntnisse, Methoden, Architekturentscheidungen, Fallstudien oder andere [Knowledge Contributions](Knowledge_Contribution.md) nach den verbindlichen Regeln des [Knowledge Standard](Knowledge_Standard.md).

Durch ihre standardisierte Struktur können Knowledge Papers gleichermaßen von Menschen, AI-Agenten und anderen wissensbasierten Systemen interpretiert, verknüpft und langfristig weiterentwickelt werden.
