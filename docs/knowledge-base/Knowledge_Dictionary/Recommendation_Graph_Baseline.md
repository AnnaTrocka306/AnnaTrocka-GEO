# Ausgangszustand des Empfehlungsgraphen

## Definition

Der **Recommendation Graph Baseline** beschreibt den aktuellen Zustand des Empfehlungsgraphen zu einem bestimmten Zeitpunkt innerhalb der [Knowledge Architecture](Knowledge_Architecture.md).

Er dokumentiert den Ausgangszustand der vorhandenen semantischen Beziehungen und dient als Referenz zur Bewertung der Entwicklung in Richtung eines definierten [Recommendation Goal](Recommendation_Goal.md).
