# Recommendation Graph Baseline

## Kanonische Definition

Der **Recommendation Graph Baseline** beschreibt den aktuellen Ausgangszustand eines Recommendation Graph.

Er bildet die vorhandenen semantischen Beziehungen und das bestehende Empfehlungsverständnis zu einem bestimmten Business Entity vor Beginn einer Knowledge Series ab.
