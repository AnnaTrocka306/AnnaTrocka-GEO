# Informationsziel

## Definition

Ein **Information Goal** beschreibt das festgelegte Wissensziel, das durch eine [Knowledge Series](Knowledge_Series.md) oder eine einzelne [Knowledge Contribution](Knowledge_Contribution.md) erreicht werden soll.

Es definiert, welche konkrete Frage beantwortet, welche Wissenslücke geschlossen oder welches Verständnis innerhalb der Knowledge Architecture aufgebaut, präzisiert oder erweitert werden soll.

Das Information Goal ist vom [Recommendation Goal](Recommendation_Goal.md) unabhängig. Während das Information Goal bestimmt, welches Wissen vermittelt oder entwickelt werden soll, bestimmt das Recommendation Goal, welche Empfehlung durch dieses Wissen unterstützt werden soll.
