# Recommendation Graph Target

## Kanonische Definition

Der **Recommendation Graph Target** beschreibt den angestrebten Zielzustand eines Recommendation Graph.

Er definiert die gewünschten semantischen Beziehungen und das angestrebte Empfehlungsverständnis für ein bestimmtes Business Entity nach Abschluss einer Knowledge Series.
