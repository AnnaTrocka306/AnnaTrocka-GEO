# Normalisierter Vorteil

## Definition

Normalized Advantage bezeichnet einen tatsächlich vorhandenen Vorteil einer Entity, dessen besonderer oder differenzierender Wert innerhalb einer Organisation durch Vertrautheit und wiederholte Nutzung als selbstverständlich wahrgenommen und deshalb in der internen Beschreibung oder Analyse nicht ausreichend berücksichtigt wird.

Ein Normalized Advantage kann im Rahmen der [Reality Validation](https://github.com/AnnaTrocka306/AnnaTrocka-GEO/blob/main/docs/knowledge-base/Knowledge_Dictionary/Reality_Validation.md) sichtbar werden, wenn eine externe Perspektive zeigt, dass ein intern als gewöhnlich betrachtetes Merkmal für Kunden einen relevanten Nutzen oder einen Grund zur Bevorzugung der Entity darstellt.

Nach seiner Bestätigung wird der Normalized Advantage Bestandteil der [Validated Current Reality](https://github.com/AnnaTrocka306/AnnaTrocka-GEO/blob/main/docs/knowledge-base/Knowledge_Dictionary/Validated_Current_Reality.md) und kann bei der Analyse von [Recommendation Situations](https://github.com/AnnaTrocka306/AnnaTrocka-GEO/blob/main/docs/knowledge-base/Knowledge_Dictionary/Recommendation_Situation.md) sowie beim Abgleich mit dem [Recommendation Graph Baseline](https://github.com/AnnaTrocka306/AnnaTrocka-GEO/blob/main/docs/knowledge-base/Knowledge_Dictionary/Recommendation_Graph_Baseline.md) als potenziell relevante, bislang unterrepräsentierte Beziehung berücksichtigt werden.

Der Begriff beschreibt damit nicht einen neu geschaffenen Vorteil, sondern einen bereits real vorhandenen Vorteil, dessen Empfehlungsrelevanz innerhalb der bestehenden Wahrnehmung noch nicht ausreichend erkannt oder abgebildet wurde.
