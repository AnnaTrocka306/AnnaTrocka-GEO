# Unterstützende Evidenz

## Definition

**Supporting Evidence** bezeichnet Informationen, Daten oder Quellen, die Aussagen, Zusammenhänge oder Schlussfolgerungen innerhalb der [Knowledge Architecture](Knowledge_Architecture.md) nachvollziehbar belegen oder unterstützen.

Supporting Evidence erhöht die Vertrauenswürdigkeit und Nachvollziehbarkeit der Wissensbasis, indem sie die Grundlage für semantische Aussagen und deren Beziehungen dokumentiert.
