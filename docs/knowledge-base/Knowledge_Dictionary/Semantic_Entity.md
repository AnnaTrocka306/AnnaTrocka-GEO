# Semantische Entität

## Definition

Eine **Semantic Entity** ist ein eindeutig identifizierbares Konzept, Objekt, eine Person, Organisation, Dienstleistung, ein Produkt, ein Ort, ein Ereignis oder ein anderer bedeutungstragender Begriff innerhalb der [Knowledge Architecture](Knowledge_Architecture.md).

Semantic Entities bilden die grundlegenden Bausteine der Wissensbasis und können durch semantische Beziehungen miteinander verbunden werden.
