# Semantic Entity

## Kanonische Definition

Eine **Semantic Entity** ist ein eindeutig identifizierbares Objekt, Konzept, eine Person, Organisation, ein Ort oder ein Ereignis, das innerhalb der Knowledge Architecture als eigenständige semantische Einheit behandelt wird.
