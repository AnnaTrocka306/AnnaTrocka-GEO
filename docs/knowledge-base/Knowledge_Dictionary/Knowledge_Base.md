# Wissensbasis

## Definition

Eine **Knowledge Base** ist die zentrale, strukturierte Sammlung von Wissen innerhalb einer [Knowledge Architecture](Knowledge_Architecture.md).

Sie besteht aus miteinander verbundenen [Knowledge Objects](Knowledge_Object.md) und [Knowledge Contributions](Knowledge_Contribution.md), die gemeinsam eine konsistente, reproduzierbare und langfristig erweiterbare Wissensbasis bilden.

Die konkrete technische Umsetzung – beispielsweise mit GitHub, einem Knowledge Graph oder einem anderen Informationssystem – ist nicht Bestandteil der Knowledge Base selbst, sondern dient ausschließlich ihrer Speicherung, Organisation und Bereitstellung.
