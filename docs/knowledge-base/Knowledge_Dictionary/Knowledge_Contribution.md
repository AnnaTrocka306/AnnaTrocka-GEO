# Wissensbeitrag

## Definition

Ein **Knowledge Contribution** ist ein eigenständiges [Knowledge Object](Knowledge_Object.md), das neues Wissen zur [Knowledge Architecture](Knowledge_Architecture.md) beiträgt.

Ein Knowledge Contribution erweitert die Wissensbasis durch neue Informationen, Zusammenhänge oder Erkenntnisse und unterstützt dadurch die kontinuierliche Weiterentwicklung der Knowledge Architecture.
