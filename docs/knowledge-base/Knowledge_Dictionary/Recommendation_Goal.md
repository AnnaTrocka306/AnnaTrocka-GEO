# Empfehlungsziel

## Definition

Ein **Recommendation Goal** ist das gewünschte Empfehlungsergebnis, das innerhalb der [Knowledge Architecture](Knowledge_Architecture.md) erreicht werden soll.

Es definiert, in welcher Empfehlungssituation ein Unternehmen, eine Person, ein Produkt oder eine Dienstleistung als geeignete Antwort empfohlen werden soll.

Ein Recommendation Goal dient als Zieldefinition für den Aufbau und die Weiterentwicklung der Wissensbasis innerhalb der Knowledge Architecture.
