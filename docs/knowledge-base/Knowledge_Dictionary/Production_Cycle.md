# Produktionszyklus

## Definition

Ein **Production Cycle** ist eine abgeschlossene Produktionseinheit zur Realisierung eines definierten Abschnitts des Recommendation Graph.

Ein Production Cycle beginnt mit den ausgewählten Knowledge Contributions und endet mit der Veröffentlichung des daraus erzeugten Content Package.
