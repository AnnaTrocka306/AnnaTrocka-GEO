# Semantische Beziehung

## Definition

Eine **Semantic Relationship** beschreibt eine bedeutungstragende Verbindung zwischen zwei oder mehreren [Semantic Entities](Semantic_Entity.md) innerhalb der [Knowledge Architecture](Knowledge_Architecture.md).

Semantic Relationships definieren, wie Semantic Entities inhaltlich miteinander verbunden sind, und bilden gemeinsam die Struktur der Wissensbasis.
