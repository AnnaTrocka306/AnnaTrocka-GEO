# Wissensstandard

## Definition

Ein **Knowledge Standard** ist ein normatives Dokument, das verbindliche Regeln für die Erstellung, Strukturierung, Pflege und Weiterentwicklung von Wissen innerhalb der [Knowledge Architecture](Knowledge_Architecture.md) definiert.

Knowledge Standards legen fest, wie [Knowledge Objects](Knowledge_Object.md) erstellt und verwaltet werden, um eine konsistente, skalierbare und qualitativ einheitliche Wissensbasis sicherzustellen.
